\#cat-eats-mouse（猫吃老鼠）



这是我大约在小学到初中时用Scratch3做的一款小游戏。



现在，它被保存到了 GitHub 上，希望能让更多人看到那个小孩子付出了好几个下午的心血做出的成果。



\## 如何游玩

\- \*\*在线试玩（推荐）\*\*：点击右侧 Releases 下方的链接，或者直接打开 \[在线游玩地址](https://SaT-hina.github.io/cat-eats-mouse/)

\- \*\*下载\*\*：下载index.html即可，这个文件就是html版完整的游戏文件。由于一些问题（可见下文背景故事），我不在Releases文件夹中上传游戏包体。



\## 背景故事

大约在我小学时，我的母亲在网上看到了编程课程的广告，于是她询问了我家族中最有学识的我的表哥，我的表哥给了一个链接，那是浙大翁恺老师在慕课上开设的C语言课。

于是我就变得很强了（bushi）。真正让我做这个游戏的动机是我的表弟去听了一个线下培训机构的编程试听课，那个教的是scratch。年少的我我轻蔑地以为这个没有什么学习的必要，

我当时觉得他可以直接学习一门程序设计语言，然后想用scratch做东西也没有门槛。

为了向表弟证明这一点，我当然得拿出我的实力。表弟表示他在那个试听课上见到了炫酷的星球大战游戏，问我能不能做出来。

我当然不可能马上做出来，不考虑软件端也要考虑大量的音画素材的问题。于是我带他剖析这个游戏，想着从简单的做起，只用scratch提供的素材。

我记忆中的这游戏就是控制飞船发射和躲避弹幕，而弹幕最简单的是直接下落，于是我当场做了一个老鼠下落，用猫接住（吃）老鼠的游戏。

这个简单的内容就是这个游戏本身，刚才我的父亲在老电脑（当时用的还是64位的win7，如今我已经有了自己的win11笔记本）上发现了我的文件夹，我才终于找到了我这款游戏。

目前的游戏版本主要的工作量在于我写完最初版的猫吃老鼠的几年后添加了较为完整的开始界面和结算动画，并提供了自己设定游戏参数的功能。其中的结算动画真的花费了我相当多的精力。

其实我做出了星球大战的初版和改进版和最终版第一版，但是都不合我意，所以现在的猫吃老鼠是最完美的版本。

当然我必须承认scratch的使用不是0门槛的，我在学习了如何使用scratch的基础上使用了其中音画的修改功能，并且scratch有相当多功能是我开始忙于应试前没能接触到的，我绝对地低估了scratch。

最后我一定要感谢一个随着设备变换，我已经丢失的伟大的免费网站，这个网站免费提供了.sb3转.html换转.exe功能，这使我的.sb3文件真正像一个游戏。

最后的最后感谢免费使用的deepseek网页端，为我提供了如何上传到GitHub的技术支持以及README的格式，写完README我还有事情要做，我不能继续研究怎么在把electron引擎版的游戏上传到Releases了。

谢谢！
